# Jobtrail

A drag-and-drop job application tracker. Move each application through Wishlist, Applied, Interview, Offer, and Closed. Applications waiting more than 7 days are flagged for a follow-up, and the board shows your reply rate.

Built with Next.js (App Router), TypeScript, and Tailwind CSS. Data is saved in your browser (localStorage), so there is no sign-up.

## Run locally
    npm install
    npm run dev

## Deploy
Push to GitHub, then import the repo in Vercel. No settings needed.
